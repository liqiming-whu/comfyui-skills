### 检查点观察

- 抽测 400、600、800、1000、1200、1400。400 已有明显人物特征；中后期均能改变服装与场景。
- 1000 作为默认起点，800/1200 作为重点备选；1400 可用，未见明显过拟合崩坏，也未显示一致胜过中期。
- 这不是严格身份排名，更不代表所有人物都应该训练到 1000 步。记录与图片支持的是本模型、本采样条件下的试用优先级。

### 别名观察

在 1000 步、强度 1、相同近景正文和两个种子下测试完整名、中文名、英文名、无名称，各配同文本同种子的无 LoRA 对照：

| 文本名称 | 观察与适用结论 |
|---|---|
| `林知微(Ada)` | 人物观感稳定，作为完整标识 |
| `林知微` | 两个种子均接近完整名，支持本轮单独使用中文名 |
| `Ada` | 有人物观感，但更接近无名称组；未证实具有与中文名同等可靠的额外触发能力 |
| 无名称、仍挂 LoRA | 面貌仍受 LoRA 影响；相似人脸本身不能证明 Ada 有效触发 |

本轮使用优先写 `林知微` 或 `林知微(Ada)`。英文独立触发仍需下一轮训练覆盖与对照验证。结论局限于 1000 步的一组近景正文、两个种子；没有验证其他 step 的完整名称矩阵、低强度或 RAW 推理。

### 画面倾向

端正头位、转脸、看向画外、张口表情与全身双鞋基本可控。直闪图能出现鼻尖/脸颊反光，但皮肤仍平滑美化；近景构图有时比要求更宽。不要沿用此前其他模型的“直闪没有镜面高光”判断来概括这轮。未做自动人脸评分；直闪与全身各只有一个种子。

原始三个场景正文保存在 [测试提示词资产](../assets/evaluation-prompts.json) 的 `ada_20261010.prompts`，已执行 API 图见 [Ada_step1000_Turbo_Base_API.json](../assets/Ada_step1000_Turbo_Base_API.json)。资产中的 LoRA 文件名与节点需要在当前服务上确认；复制历史 API 文件不代表今天已执行。

## Xiaoling v3：项目提示词作为测试示例

来源：[模型页](https://huggingface.co/venusleeyous/xiaoling-lora)、[evaluation.json](https://huggingface.co/venusleeyous/xiaoling-lora/raw/main/evaluation.json)，2026-10-11 读取。触发词 `xiaoling`，发布的检查点为 800、1000、1050、1200、1400；其生成记录包含七组 × 五个检查点的 35 张图片。这里核对了项目文字与参数，没有重新生成或对这 35 张图做新的视觉排名。

七组原文逐字保存于 [测试提示词资产](../assets/evaluation-prompts.json) 的 `xiaoling_v3.prompts`：

| ID | 固定种子 | 用途 |
|---|---|---|
| p1 | 101 | 图书馆正面、平静表情、绿毛衣 |
| p2 | 102 | 地铁站朝画面左侧的 3/4 转脸、不看镜头 |
| p3 | 103 | 美术馆行走回望、风衣 |
| p4 | 104 | 屋顶暮色、自然笑容、轻微向右转脸 |
| p5 | 105 | 山间朝画面左侧的侧脸 |
| p6 | 106 | 散发替代发髻、服装变化 |
| hair | 105 | 朝画面右侧的侧脸、下颌长度波浪短发 |

保留原始 ID、种子和正文，项目原参数在资产的 `generation`。跨模型测试时只替换一次身份触发词并换对应 LoRA，例如把原文 `xiaoling` 替换为 `林知微(Ada)`；测试别名时分别替换为 `林知微`、`Ada`，无名称组连同紧邻的多余标点一起去掉，其他正文保持一致。生成提示词不是训练 caption，不把这里的身份保持要求或否定措辞直接写入逐图事实描述。

固定种子便于同条件比较，但不是覆盖全部随机性的保证。每组补多个种子及无 LoRA 对照再评估。七组主要使用柔光和近景/半身；不能单独验收硬光质感、全身、手部或头部左右倾斜。可加用林知微案例的直闪、全身和端正头位正文，按需求补手部活动条件。

P6 的“different from her usual clothing”没有定义具体衣服，适合作为历史复现例；要测明确服装服从，另建写明衣物的新条件，不悄悄改原文。H 的无绑发要求属于生成指令，不等于实际图片已做到。
