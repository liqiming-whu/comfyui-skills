# 图像与分布审查

## 先审查正式数据集

确认图片全集与历史副本范围，逐图检查身份、清晰度、畸变和 caption 对应关系。保留原图与可恢复基线。正式目录只接收已验收的图文对，拒收样本和服务错误记在制作日志。

统计以下分布，注明是逐图观察还是文字词表命中：正面/侧面、景别、表情、看镜头/看别处、头部侧倾、配饰、服装、光照和场景。关键词为 0 只能标作“未命中”；少量抽样不能证明全集不存在该属性。

全图亮度标准差受背景和衣服影响，不能代表面部硬光；灰度阈值不能等同镜面高光；边缘能量不能代表皮肤细节。需要量化时明确面部区域、计算方法和人工观察依据，任何单一统计都只作辅助。

## 补图由缺口决定

人物身份稳定的前提下，按已有分布选择补图维度。可把一张图分配到多个配额，但不要把背景变化当成面部光照变化。

| 已确认缺口 | 补图方向 |
|---|---|
| 柔光占绝大多数 | 较硬日光、直闪或有清楚阴影的场景；检查脸部实际响应 |
| 几乎都看镜头 | 阅读、行走、整理物品等简单活动，明确包含看向别处 |
| 固定发饰或服装 | 无发饰、不同发饰或衣着变化，caption 按图描述 |
| 同侧歪头过多 | 优先补自然端正图；保留需要的侧脸、低头和抬头 |
| 构图过于单一 | 按用户需要补全身、横版或自然活动场景，保证脸仍可辨认 |
| 美化肤质过于一致 | 能保留身份且确实呈现细节或适量颗粒的样本，不追求脸部失焦 |

20 张是可用于迭代的起始规模，比例目标按任务设计；不能承诺某比例必然解耦。若原有 x/N 张歪头，新增 u 张端正、t 张歪头，新增后的比例为 `(x+t)/(N+u+t)`。镜像歪头样本仍是歪头样本。

## 获取与处理

- 收集或拍摄：质量足以支持训练分辨率与身份辨认即可，不设普遍的短边 1024 硬门槛。风格数据的色彩一致性与人物数据的光照多样性按目标区分。
- 生成：用原始参考锚定人物，逐张检查身份漂移。已有 LoRA 的大量自生成可能延续偏差；优先用独立参考约束并筛选。
- 原始采样参数、生成平台和身份保持方式应分别记录。使用当前环境实际可用的生成方式，不为了统一参数擅自换平台。
- 清理：检查可解码性、格式扩展名、重复与近似重复；分享前检查 GPS 等敏感元数据，保留原始档案并记录处理。
- 近似重复只提出复核，不自动删除。重复会改变有效权重，镜像和裁切的样本数不等于独立身份信息量。

使用官方仓库推理时，RAW 的 52 步/CFG 3.5 与 Turbo 的 8 步/CFG 0/mu 1.15 是推荐设置；仅在对应实现中使用。见 [来源与适用范围](quick-reference.md)。

## 验收补图效果

素材验收确认逐图身份、实际可见条件和配额；模型验收另用固定条件比较训练前后身份保持、条件服从和默认倾向。素材通过不代表训练收益已经证明。
