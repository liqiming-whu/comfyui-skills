# 图像与分布审查

## 先审查正式数据集

确认图片全集与历史副本范围，逐图检查身份、清晰度、畸变和 caption 对应关系。保留原图与可恢复基线。正式目录只接收已验收的图文对，拒收样本和服务错误记在制作日志。

用户指定已有参考时，先准确找到图片与对应 caption，核对版本、文件名和配对，再逐张查看。缺失或不能确认选定版本时向用户核实，不用早期版本或自行猜测的文件替代。区分身份参考、风格参考和已经计入训练配额的样本；参考数量与最终样本数不能混算。

用户要求原件不变时，保留图片与 caption 字节，复制入正式目录和参考备份后比较哈希。统一命名只创建副本并记录对应关系。处理原件、修订 caption 和修改正式副本的授权分别沿用当前任务约定。

统计以下分布，注明是逐图观察还是文字词表命中：正面/侧面、景别、表情、看镜头/看别处、头部侧倾、配饰、服装、光照和场景。关键词为 0 只能标作“未命中”；少量抽样不能证明全集不存在该属性。

全图亮度标准差受背景和衣服影响，不能代表面部硬光；灰度阈值不能等同镜面高光；边缘能量不能代表皮肤细节。需要量化时明确面部区域、计算方法和人工观察依据，任何单一统计都只作辅助。

## 补图由缺口决定

人物身份稳定的前提下，按已有分布选择补图维度。可把一张图分配到多个配额，但不要把背景变化当成面部光照变化。

| 已确认缺口 | 补图方向 |
|---|---|
| 柔光占绝大多数 | 较硬日光、直闪或有清楚阴影的场景；检查脸部实际响应 |
| 几乎都看镜头 | 阅读、行走、整理物品等简单活动，明确包含看向别处 |
| 固定发饰或服装 | 无发饰、不同发饰或衣着变化，caption 按图描述 |
| 同侧歪头过多 | 优先补自然端正图；保留需要的侧脸、低头和抬头 |
| 构图过于单一 | 按用户需要补全身、横版或自然活动场景，保证脸仍可辨认 |
| 美化肤质过于一致 | 能保留身份且确实呈现细节或适量颗粒的样本，不追求脸部失焦 |

数据规模与比例目标按任务设计，可先做少量代表样本验证制作方法；不能承诺某比例必然解耦。若原有 x/N 张歪头，新增 u 张端正、t 张歪头，新增后的比例为 `(x+t)/(N+u+t)`。镜像歪头样本仍是歪头样本。

## 生成前建立逐图多样性计划

先明确用户希望保持的核心特征与希望变化的属性。语言、风格、时代、服装体系、角色外貌和配额由用户输入决定；不默认写实摄影、古代场景、特定颜色、特定年龄或固定样本数。下列维度是按需选择的规划工具，不要求每个项目覆盖所有项。

把总目标、已有合格数量、待新增数量按类别列出，新增量为目标减去已有合格样本。时代、场景类型、人物/环境构图及方向等交叉配额分别对账，确认各小计与总量一致。原始样本若不能满足合格标准，单独记录保留要求与验收冲突，不把计划数量当成接受数量。

| 维度 | 可选变化与检查重点 |
|---|---|
| 视角与机位 | 正面、左右三分之四、接近侧面、轻微俯仰、自然回眸；区分人物朝向与镜头位置，真实生成视角变化 |
| 景别与活动 | 头肩、胸像、半身、膝上、全身；站、坐、行走及与场景相关的活动；人物与环境结合时脸仍应足以辨认 |
| 头位与视线 | 按设定安排自然端正、低头、抬头、少量侧倾、看镜头与看别处，避免所有图同侧歪头或低头 |
| 发型与配饰 | 在用户允许范围内变化披发、扎发、编发、盘发及有无饰物；变化造型不应同时改变身份 |
| 衣着 | 款式、材质、颜色、正式程度和行动便利性；日常与特殊造型按用途搭配，避免某套衣服占据所有条件 |
| 表情 | 平静、浅笑、开心、专注、思考、惊讶、认真、羞涩或疲倦等适合角色的状态；检查是否实际可见，避免夸张导致身份变化 |
| 光线 | 不同时间、阴晴、室内外、窗光、侧光、灯光及任务允许的特殊光；变化应发生在主体上，关键身份特征仍可辨认 |
| 场景与道具 | 按用户世界观与时代安排可信环境；活动、道具和服装互相符合，背景变化不替代人物变化 |
| 视觉风格 | 用户要求固定风格时保持一致；允许跨风格时按计划变化，并分别复核身份与风格符合度 |

合理交叉这些维度，不把某发型永远绑定一件衣服、某表情永远绑定一种光线或某视角永远绑定一个场景。关键可控属性尽量出现在多个组合中；无需穷举全部笛卡尔组合，也不靠更换 caption 同义词制造多样性。

逐图计划至少记录编号、批次、目标类别、视角/景别、头位/视线、发型/配饰、衣着、表情、动作、场景/道具、光线和参考来源。图像尺寸与方向记录在计划或 metadata，不写入训练 caption。计划与生成后实际属性分开记录；未实现的条件改记实际结果，并据此补缺口。

## 人物身份一致性检查

以用户确认的原始身份参考为稳定依据，优先使用正脸与两侧角度共同判断。生成工具能接收多张参考时使用这些锚点；不能全部传入时记录实际使用范围，仍回到原始参考复核。不把上一张或连续新生成的图片当成下一张的唯一身份依据，避免逐代漂移。

逐张与原始参考比较眼形及间距、眉形、鼻梁与鼻尖、唇形、脸部轮廓与下颌、五官相对位置、年龄感和整体辨识度。区分表情、透视、光线和用户风格带来的合理变化与身份改变；发型、衣着和配饰相同不能作为身份相同的证据。非人角色按用户设定替换为对应的稳定结构特征。

大幅侧脸、强光影、全身和遮挡样本提高复核强度，必要时放大脸部或生成审核裁片，并与相近角度参考比较；裁片只用于审核。脸太小或主要特征不可辨认时不能凭服装判断通过。明显漂移应拒收并修正参考使用或重做；连续发生漂移时暂停该生成方式，核实参考与工具限制后再继续，不为凑数量接受。

## 分批制作与质量审核

按小批次完成制作，通常每批约5—10张，可按任务规模、工具成本与审核能力调整；先通过代表样本，再扩展覆盖。每批完整执行生成、保存、逐图审核、caption 编写与对账、配额统计后，再进入下一批，不等全部生成结束才检查身份。

每批检查：

1. 回到原始参考逐张比较身份，特别复核侧脸、强光影和全身。
2. 检查面部、手部、肢体与身体比例，以及用户风格下的清晰度、质感、文字、标志和其他瑕疵。
3. 检查服饰、发型、道具和动作是否符合场景、时代及用户设定；人物与环境结合时主体仍清楚。
4. 对比本批与此前接受样本的视角、表情、衣着、发型、光线和场景，检查重复、条件绑定与分布缺口。
5. 根据最终图像独立写 caption 并逐项核对，删除未出现的细节，检查触发词、用户语言要求及比例/画幅说明。
6. 仅将通过的图文对计入配额。拒收项另存原因和重做关系，重做后重新审核；更新实际清单再规划下一批。

每批保存已完成的图片、caption、生成来源或提示词、实际属性、接受/拒收状态与审核记录，以便中断后从真实进度继续。必要时制作批次与总体联系表查看分布，细节回到单图；联系表不作为训练样本。工具不可用、参考缺失或身份漂移无法纠正时，如实报告已接受数量与缺项，不用重复图、空文件、裁片或拼图补数。

## 获取与处理

- 收集或拍摄：质量足以支持训练分辨率与身份辨认即可，不设普遍的短边 1024 硬门槛。风格数据的色彩一致性与人物数据的光照多样性按目标区分。
- 生成：用原始参考锚定人物，逐张检查身份漂移。已有 LoRA 的大量自生成可能延续偏差；优先用独立参考约束并筛选。
- 原始采样参数、生成平台和身份保持方式应分别记录。使用当前环境实际可用的生成方式，不为了统一参数擅自换平台。
- 清理：检查可解码性、格式扩展名、重复与近似重复；分享前检查 GPS 等敏感元数据，保留原始档案并记录处理。
- 近似重复只提出复核，不自动删除。重复会改变有效权重，镜像和裁切的样本数不等于独立身份信息量。

使用官方仓库推理时，RAW 的 52 步/CFG 3.5 与 Turbo 的 8 步/CFG 0/mu 1.15 是推荐设置；仅在对应实现中使用。见 [来源与适用范围](quick-reference.md)。

## 验收补图效果

素材验收确认逐图身份、实际可见条件和配额；模型验收另用固定条件比较训练前后身份保持、条件服从和默认倾向。素材通过不代表训练收益已经证明。
