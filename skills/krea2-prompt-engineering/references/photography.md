# 摄影词库

## 镜头

默认选一个主镜头，并把术语展开为可见效果。焦段按全画幅等效理解，仅是构图提示，不是生成器真实相机设置。

| 镜头 | 可组合句式 |
| --- | --- |
| 广角 | 广角视野，近景突出，环境纵深明显，边缘有轻微拉伸 |
| 超广角 | 极近前景与远处环境形成夸张尺度对比；主体重要部位避开边缘 |
| 鱼眼 | 鱼眼视野，明显桶状畸变与弯曲边缘；仅在有意需要变形时使用 |
| 中长焦人像 | 85–135mm 人像视角，拍摄距离适当，五官比例自然，背景柔和虚化 |
| 长焦压缩 | 从较远位置以长焦取景，前后景看起来更贴近，空间层次压缩 |
| 微距 | 极近细节，纹理突出，对焦区域很窄；不用来同时要求完整全身 |
| 移轴 | 倾斜焦平面形成选择性清晰区域；只有需要微缩感时才明确该效果 |

透视主要由相机位置和距离决定，不把焦段说成固定的“无畸变保证”。移轴也可校正建筑透视，不等同于必然微缩。

## 主视角

自由创作默认从下表选择，用户指定视角优先。倾斜属于画面旋转，可与一个相机位置组合，但不要列出互斥机位。

| 视角 | 画面与叙事 |
| --- | --- |
| 低角度 | 从较低处仰拍，主体显得高大、自信 |
| 高角度 | 从上方斜俯拍，环境和姿态更清楚，人物显得轻巧 |
| 侧后方 45° | 从侧后捕捉回头或行进姿态，保留动作方向 |
| Dutch angle | 画面轻倾约 15°，增强动态或不安感 |
| 鸟瞰 | 垂直俯视，突出地面几何、位置与负空间 |
| 虫视 | 接近地面仰视，前景尺度夸张，适合明确的力量感 |
| 过肩 | 肩部形成柔和前景，主体与另一空间建立关系；摆拍语境 |
| 镜面反射 | 镜外人物与同一人的镜中反射共同入画 |
| 框架内视角 | 门框、窗框或枝叶形成前景边界，聚焦主体 |

> **视角决定目标能不能被读出来。** 轮廓**内部**的形态（下腹、腰胯、肩背厚度等沿深度方向的变化）在正面平视下只能靠明暗与边缘曲率间接读出，是读数最弱的一档；侧向机位（正侧、四分之三侧）配合侧向主光能把同一变化写成剪影变化，读数明显更强。目标是这类局部形态时优先侧向机位；必须交付正面校准照时，先出一版侧向对照再定稿。

> **视角与覆盖。** 官方版不产裸露，选视角只需考虑构图与可读性；社区 NSFW 强化版下才把覆盖纳入取景考虑（低角度配裙装等组合，见 SKILL.md **2.3**）。

## 景深与光线

- 浅景深：背景柔和失焦，主体关键部位清晰。中长焦、较近主体和较远背景通常更容易形成该视觉效果。
- 大景深：前后环境可辨，适合广角全身与空间叙事。
- 选择性对焦：明确落在眼睛、服装细节或镜中人脸，其他区域逐渐柔化。
- 广角低机位全身默认较深景深；不要不加距离条件就再写极浅景深与巨大光斑。若光斑是重点，改为中长焦、拉开背景距离，或明确特殊拍摄条件。
- 侧窗漫射光：柔和高光与渐变阴影；侧逆光：勾勒轮廓及材质；硬顶光：脸部阴影较深，按需补光。
- 指定一个主光源，再添加有位置的补光/轮廓光。避免同一表面同时“完全哑光”和“镜面反射”。

## 镜面空间

> ⚠️ **镜面反射核心铁律**：必须先写人物在镜外的物理位置（「背对镜头，面向镜子」「坐于镜前」），再写镜中倒影。严禁只写「镜子中映出人物」——模型看到"镜子+人物"会本能地把人塞进镜面里，而不是理解为光学反射。镜框必须作为空间边界显式写出。

先写镜外人物的实际位置与朝向，再写镜框及镜中同一人的反射，最后指定对焦。例：“她背对相机站在落地镜前，面向镜子。镜框左侧是她的真实背影，镜内可见她的正面和身后房间的反射。”

对焦镜中面部时镜外近景可柔化；不要同时要求所有距离绝对锐利与极浅景深。相机避开镜面直接回射方向时要用合理偏角，不保证一句提示就能消除相机倒影。输出检查人物数、左右关系与反射方向；使用社区 NSFW 强化版时另查覆盖状态。

## 构图

| 方式 | 展开 |
| --- | --- |
| 三分法 | 主体位于一侧三分线，另一侧留环境或呼吸空间 |
| 对角线 | 姿态或环境线条沿对角延伸，视线流动清楚 |
| 框架 | 门窗或镜框构成内画框 |
| 镜面 | 镜外真实人物与镜内反射分区，保持物理对应 |
| 负空间 | 大面积简洁背景强调主体尺度 |
| 引导线 | 地板、走廊或窗框线条汇向主体 |
| 中心对称 | 主体居中、环境左右呼应，适合庄重场景 |
| 前景遮挡 | 少量虚化前景增加层次，不遮住核心视觉目标 |

选一项主构图，辅助项必须与之兼容。不要为追求戏剧感自动改变用户指定的正面校准照。

> 取景句在提示词里的**位置**同样有实测影响：把 `Full-length portrait from head to toe.` 提到核心形态句之前，局部形态的分档表现会被压平（最高档几乎归零）。取景句应排在主体句与环境句之后，构图本身靠核心句内部的常量前缀锁定——详见[提示方法](prompt-method.md)「语序与层级」。
