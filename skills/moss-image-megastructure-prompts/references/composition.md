# 构图方法与示例检查

## 从 Krea 方法迁移什么

复用尺度参照、可读结构、近中远大气层次、方向主光、相机位置和媒介；将七层当作创作检查项，而非固定句法或强制填充清单。不要迁移 Krea 专用 creativity、模型档位和未经 MOSS 实测的词序/量化结论。保留原 Krea Skill。

先明确空间关系，再决定是否需要坐标。给巨构增加细节，直到体量与结构可读即可；留白有叙事作用时不强迫主体填满画框。每个尺度锚点都要在图像尺寸下能辨认。

## 倒悬双城（1536×864，16:9）

这是同一场景的 Caption / Layout 对照，不声称像素级复现此前图片。具体像素是本工具首例的可修改设计选择，不是用户已有测量值。

- 上城体 [0,0,1536,336]；下城体 [0,528,1536,864]。
- 上城向下中央塔尖 [752,320,784,408]；下城向上中央塔尖 [752,456,784,544]。两塔在 x=768 轴线上，相距 48 px（画高约 5.56%）。
- 塔与城体相接处各重叠 16 px，只控制突出部分，避免把整城重复两次。
- 气球 [824,418,840,446]，宽 16、高 28 px（画高约 3.24%，宽约 1.04%）；位于间隙中央偏右，距两端各 10 px，不挡住轴线上最近的塔尖。
- 中央留白不是规则矩形：48 px 是最近塔尖的距离，两侧天际线退让形成更宽的空气带。薄云留在后方，不能遮掉尖端或气球。不要给云、空白、光束逐一加框。
- 上城与下城是上下倒转对应的两座实体城市，不是水面反射。上城街道的水与碎屑沿画面向上回升；瀑流不跨中央间隙。
- 两座城受同一个画面左侧低位夕阳照明；左向立面暖亮，向右阴影冷蓝。城倒转不意味着太阳也倒转。
- 24 mm 广角远观，中央水平缝隙位于画面中部；用拱廊和层叠露台建立可读尺度，远端衰减进雾，避免每一平方厘米都塞满装饰。

Layout 不能编码精确轮廓、空洞或硬遮挡。塔尖终止点、云透明度与光向仍是模型执行目标，静态测试验证的是草稿几何与文字约束，不是已生成画面的遵循率。若后续实测过度碎裂，先合并塔与城体并加强文字关系；如果气球不可辨认，可适度放大或增加色彩分离，并重新检查留白。

## 环门穿航（1536×1024）

用一个完整环门框保留环的连续性；用长船框穿过中央孔洞，用小艇作尺度锚点。环孔由文字描述，不能用 bbox 表示“挖空”。船的远端在后侧环缘后面、近端在前侧环缘前面：描述这一关系，不把 items 数组顺序当 z-index。独立框定的只是环、主船、小艇，共三个物体。

## 深渊长桥（1536×864）

左/右崖各一个框，桥横跨两侧岩壁并与其重叠，人物脚部位于桥面。雾与远处裂谷用 summary 描述；不把整片深渊框成黑色物体。检查桥端是否接入崖壁、人物是否落在桥面高度、桥下空间是否开放。

## 海中巨门：保留 Caption

一座石门、平静海面、一只小舟，采用海平面随手摄影式构图。门偏画面左侧，小舟在右下、天空留白。不要求精确门洞、海平线或船坐标，不值得强制 Layout。保留自然反射与轻微不对称。

## 后续实测记录

本包只做静态验证。若用户另行授权生成，固定模型标识、画布和采样配置，分别记录 Caption/Layout 的输入、seed、结果和每项关系的观察。不同模式的比较不宣称其噪声轨迹相同；单张失败不推出模式整体优劣。
